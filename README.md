# Aurum Legal Solutions

A premium multi-page website for Aurum Legal Solutions — a client-focused Australian law firm.

## Tech Stack

- Next.js 14 (App Router)
- Tailwind CSS
- Framer Motion
- React Hook Form
- Lucide React icons

## Getting Started

From the project root (`lOGO SAMPLE`):

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

For production:

```bash
npm run build
npm start
```

## Pages

- `/` — Home
- `/about` — About Us
- `/practice-areas` — Practice Areas overview
- `/practice-areas/[slug]` — Individual practice area pages
- `/services` — Our Services
- `/resources` — Resources
- `/contact` — Contact form
- `/book-consultation` — Consultation booking form

## Deployment

Deploy to [Vercel](https://vercel.com) with zero configuration.

```bash
npm run build
```
